Wake-on-LAN (WOL)

Help

Whenever a client connects or starts playback, the plugin checks whether your storage server is awake and sends a magic packet if it is not.

Storage server

Colon, dash, dot or bare notations are all accepted.
Used to check whether the server is already awake. Leave empty to always send a packet.
A port the server listens on when it is up. 445 for SMB, 2049 for NFS, 22 for SSH.

Wake-on-LAN packet

Almost always 9. Some devices expect 7.
Minimum time between two checks or packets. Prevents flooding the network when many clients connect at once.
Sends a magic packet using the values above without saving them.
